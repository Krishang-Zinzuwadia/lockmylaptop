# Phase Workflow

## Branching
- Active branch: `dev`
- All implementation work is committed to `dev`

## Delivery Rule
For every phase:
1. Implement phase scope.
2. Validate basic behavior (or static review when toolchains are unavailable).
3. Commit all phase changes.
4. Push phase commit to origin/dev.

## Current Phase Map
- Phase 0: Requirements and setup
- Phase 1: Base app + agent foundation
- Phase 2: 4-digit pairing flow
- Phase 3: Lock + sleep command pipeline
- Phase 4: Settings and unpair
- Phase 5: Reliability and security hardening
- Phase 6: Testing and release prep
